# StockFlow — Inventory & Supply Chain Management

MERN starter project with a forest-green, warm-ivory and sage frontend.

## Project structure
- `frontend/` — React + Vite UI for Dashboard, Stock Anomalies, Batch & Expiry, Notifications, and Profit & Loss Analytics.
- `backend/` — Express starter and folders for models, controllers, routes, services and middleware.

## Run the frontend
```bash
cd frontend
npm install
npm run dev
```

## Run the backend
```bash
cd backend
npm install
npm run dev
```

The frontend currently uses illustrative sample data. MongoDB and API integration are the next development phase. Copy `.env.example` to `.env` and add your MongoDB connection string when configuring the database.
