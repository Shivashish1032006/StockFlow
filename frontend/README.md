# StockFlow Frontend

A React + Vite frontend starter for StockFlow — Inventory & Supply Chain Management.

## Features included
- Forest-green / warm ivory visual system
- Responsive sidebar navigation
- Overview dashboard with KPI cards and sales chart
- Stock anomaly investigation table
- Batch and expiry management
- Smart notification center
- Profit and loss analytics

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

## Notes
This frontend currently uses illustrative sample data. It is not connected to a backend yet.
Set `VITE_API_BASE_URL` in a local `.env` file when the Express API is ready.
